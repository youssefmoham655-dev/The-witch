# **The witch**
## A static front-end webpage built with **HTML** and **CSS** presenting an imaginary online marketplace with humorus products. This project focuses on UI design layout structuring, and styling practice without any back-end functionaity.
---
## ⚠️This is NOT a real online store
## 🚀 Highlights
- 🎨 Fictional product showcase with themed visuals
- 🧱 Clean layout using semantic HTML structure
- 🧭 Navigation bar for multi-page browsing (static)
- 🧾 Product cards and product detail sections
- 📝 Contact form UI (non-functional)
- 🔐 Login & signup page layouts (non-functional UI only)
## 🧠 Purpose

This project was created to practice and demonstrate:

- Semantic HTML structure
- CSS styling and layout techniques
- Building e-commerce-style UI components
- Responsive front-end design
- Visual storytelling through interface design

## ⚙️ How to Use

This is a **static website only**.

1. Download or clone the repository
2. Open `index.html` in any modern web browser
3. Navigate through pages using the UI links

No installation, build steps, or dependencies are required.

---

## 🚫 Limitations

This project is strictly front-end and does NOT include any backend functionality.

The following features are **not implemented**:

- ❌ Product purchasing
- ❌ Shopping cart system
- ❌ Checkout or payment processing
- ❌ User authentication (login/signup does not work)
- ❌ Account creation or user profiles
- ❌ Backend server or API integration
- ❌ Database storage
- ❌ Email/contact form submission
- ❌ Data persistence or dynamic content

All forms and interactive elements are **visual only** and do not process or store any data.
